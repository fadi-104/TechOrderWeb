اطلب طعامك بذكاء وسهولة

تطبيق TechOrder هو منصة متكاملة لطلب الطعام من مطاعمك المفضلة أو عبر خدمة الديليفري. واجهة سهلة الاستخدام، وتوصيل سريع وموثوق.

مميزات التطبيق

🍔

عدة مطاعم

تعاون مع عدة مطاعم لتوفير خيارات أوسع وتجربة طلب أكثر تنوعاً

🎙️

تسجيل صوتي للخدمات

كافة خدمات التوصيل يمكن طلبها بسهولة عبر تسجيل صوتي واضح وسريع

⚡

توصيل سريع

نضمن سرعة عالية في تنفيذ الطلبات والوصول إلى العميل بأقصر وقت

🔒

بساطة وسهولة وأمان

واجهة بسيطة وسهلة الاستخدام مع حماية عالية لبيانات المستخدم وطلباته

واجهات التطبيق

اكتشف واجهة التطبيق الجميلة والسهلة الاستخدام. صور توضيحية لكل شاشة من شاشات التطبيق لتجربة مستخدم سلسة وممتعة.

📝 صفحة التسجيل

انشئ حسابك الخاص بسهولة من خلال إدخال:

  • ✓ رقم الهاتف: لتلقي إشعارات الطلبات والعروض
  • ✓ الاسم الكامل: لتخصيص تجربتك
  • ✓ كلمة المرور: لحماية حسابك (يجب ان تكون على الاقل من 6 خانات)

🔐 صفحة تسجيل الدخول

دخول سريع وآمن لحسابك الخاص من خلال:

  • ✓ رقم الهاتف: المسجل في الحساب
  • ✓ كلمة المرور: الخاصة بك

📋 اختيار نوع الطلب

اختر طريقة الطلب المناسبة لك:

  • ✓ طلب من مطعم موجود: اختر من قائمة المطاعم المتعاقدة
  • ✓ طلب من ديليفري: اطلب أي شيء والتطبيق يوفره
  • ✓ واجهة بسيطة مع أيقونات واضحة
  • ✓ انتقال سلس بين الخيارات

🏪 صفحة عرض المطاعم

قائمة مطاعمنا المتعاقدة بسهولة:

  • ✓ صور المطاعم وأسماؤها

🍽️ قائمة المأكولات

قائمة شاملة بجميع الوجبات والأسعار:

  • ✓ صور الوجبات عالية الجودة
  • ✓ أسماء وأسعار الوجبات
  • ✓ أزرار كمية (+/-): لتحديد عدد الوجبات
  • ✓ عرض الكمية الحالية المختارة
  • ✓ وصف الوجبة

📦 إدخال باقي معلومات الطلب

بعد اختيار الطعام، يطلب التطبيق باقي المعلومات اللازمة لتجهيز الطلب:

  • عرض الطلبات المختارة مع الكمية وسعر كل صنف مضروبا بكميته المحددة
  • ✓ اختيار الحي من قائمة الأحياء المتاحة
  • ✓ عنوان التسليم أو الموقع
  • ✓ تفاصيل الملاحظات الخاصة بالطلب
  • ✓ عرض سعر الوجبات مع سعر التوصيل مع الاجمالي
  • ✓ تأكيد الطلب قبل الإرسال

🎙️ واجهة الطلب الصوتي

خدمة الطلب الصوتي تجعل التفاعل مع التطبيق أسرع وأسهل:

  • ✓ تسجيل صوتي مباشر لتحديد الطلب
  • ✓ فهم أوامر المستخدم بدقة وسرعة
  • ✓ عرض الملاحظات الصوتية بشكل واضح

واجهة تتبع طلباتي

مراجعة شاملة لجميع طلباتي وحسب التاريح:

  • ✓ قائمة الطلبات التي تم انشاءها
  • ✓ تتبع حالة الطلب: تتبع حالة كل طلب ومعرفة المرحلة التي وصل لها
  • ✓ عرض التفاصيل: عرض تفاصيل كل طلب ونوعه

الأسئلة الشائعة

هل التطبيق آمن؟ ▼

نعم، التطبيق يستخدم أحدث تقنيات الأمان والتشفير لحماية بيانات المستخدمين والعمليات المالية.

ما هي رسوم التوصيل؟ ▼

تختلف رسوم التوصيل حسب الحي والمسافة. يتم عرضها بوضوح قبل تأكيد الطلب.

كم يستغرق وقت التوصيل؟ ▼

يتراوح وقت التوصيل من 30-45 دقيقة حسب المطعم والموقع. يتم تحديثك بشكل مستمر.

هل يمكن إلغاء الطلب؟ ▼

نعم، يمكنك إلغاء الطلب قبل تحضيره من المطعم.
